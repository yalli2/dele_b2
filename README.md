# DELE B2 대비 학습실

국제학교 스페인어 DELE B2 시험대비 수업용 인터랙티브 사이트입니다.

- 모의시험 7회분 (독해·듣기·쓰기·말하기), 7회는 해설 포함
- 독해·듣기 문항은 바로 풀고 채점 (점수·해설 표시, 브라우저에 기록 저장)
- 듣기: 원어민 음성(브라우저 TTS, Edge의 Natural 음성 권장) — 남녀 목소리로 대화 재생
- 쓰기: 단어 수 자동 계산, 자기 점검표, 모범답안
- 말하기: 준비 타이머, 녹음 후 다시 듣기, 면접관 질문 음성

참고 교재: 『Preparación al Diploma de Español, Nivel B2』(Edelsa)의 시험 구성과 주제.
지문·문항·듣기 스크립트는 저작권 보호를 위해 수업용으로 새로 각색했습니다.
